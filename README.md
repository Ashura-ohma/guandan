# 星曜掼蛋 · Neon Guandan

一款原创、离线、中文的双人搭档掼蛋游戏。绿金色牌桌、清晰纸牌、原创轻音乐与音效；1 位玩家 + 3 位 AI，无广告、登录、联网权限或付费功能。

## 三种玩法

- **经典升级**：两队从 2 升到 A，设备本地保存队伍级数
- **快速开局**：随机级牌，独立对局
- **明牌练习**：通过「牌局记录」查看四家手牌，学习组合

另有三档启发式 AI、出牌提示、托管、理牌、牌局记录、音效与速度设置。AI 仅使用自己的手牌和公共信息，不窥探对方牌面。提示提供合法组合，并非最优博弈求解器。

## 规则范围：休闲升级版

108 张双副牌，每人 27 张，0/2 号座位与 1/3 号座位各为一队。支持单张、对子、三张、三带二、五张顺子、三连对、两连三张（钢板）、四张及以上同点数炸弹、同花顺、四王炸。

- 级牌高于 A，大小王仍更大；顺子类使用自然点数，A 可最小或最大，不可绕回
- 红桃级牌可替代普通牌的点数和花色，不能替代王；单出按级牌
- 同花顺大于五张及以下炸弹，小于六张及以上炸弹；四王炸最大
- 同类普通牌比较牌型主点数；炸弹先比张数再比点数
- 全部其余有效玩家不出后恢复自由领出；最后出牌者已走完则由仍有牌的搭档接风
- 头游方获胜，搭档二游/三游/末游分别升 3/2/1 级；双上时立即结算，未走完的两位显示「双下」，不虚构其顺序
- 必须实打 A；打 A 时搭档进入前三方可通关，之后两队重置为 2

**本版本不含进贡、还贡、抗贡、连续三次不过 A 退级等规则，不是完整赛事规则实现；不含真人联网。**

## 本地运行

需要 Python 3；测试需要 Node.js 18+。没有 npm 运行时依赖。

```sh
npm start
# 打开 http://localhost:8080
npm test
```

Android 构建与签名方法见 [android/README.md](android/README.md)。签名密钥必须由开发者私下备份，绝不放进仓库或源码压缩包。

## 文件结构

- `engine.js`：可独立使用的规则、牌局与 AI 模块
- `game.js`：交互、存储、模式与教程
- `hand-layout.js`：可独立测试的手牌布局、排序和选牌反馈
- `audio.js`：原创离线音乐、音效和音频生命周期
- `AUDIO.md`：音频接口与原创授权说明
- `index.html` / `style.css`：响应式中文界面
- `tests/`：规则、模拟对局与 UI 状态测试
- `android/`：原生离线 WebView 包装与可复现构建脚本
- `downloads/`：已签名安装包与 SHA-256

### Android 设备验收重点

保留旧版数据覆盖安装 → 检查存档和统计 → 点 ♫ 开启音乐并独立调整音效 → 切后台确认静音 → 展开大牌、撤销、预选 → 连续旋转并完整打一局 → 回看记录。特别检查 320×568、390×844、568×320、844×390 的标准/大字/分组模式、手牌滑动和底部按钮，以及来电、耳机切换、快速后台恢复。源码计算发现的窄屏溢出与控件重叠已处理，但实际渲染和设备听感仍未验证。
